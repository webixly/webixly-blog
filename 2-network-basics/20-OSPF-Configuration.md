# 🔀 Network Routing (Connecting Departments)

## 🧠 Context

After creating VLANs for different departments (IT, HR, Sales),
each network was isolated and could not communicate with others.

---

## 🎯 Problem

Devices in different VLANs could not communicate.

---

## 🚀 Solution: Routing

To solve this, I implemented routing using a router.

This allows communication between different networks.

---

## ⚙️ Implementation

* Connected router to switch
* Configured interfaces
* Assigned IP gateways for each VLAN

---

## 🧪 Result

* IT ↔ HR communication works
* HR ↔ Sales communication works
* Full network connectivity achieved

---

## 💡 What I Learned

* VLANs isolate networks
* Routing connects networks
* A router is required for inter-network communication

---

## 📌 Conclusion

Routing is essential to transform isolated VLANs into a fully connected network.
